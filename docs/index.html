Everything a phone app needs, and nothing that phones home

Every feature below works with the phone in aeroplane mode. There is no code path that could upload a call log, because the app is not allowed to open a socket.

T9 search

Type a number and names match as you go — 5 maps to J, K and L, exactly like the keypad you grew up with.

Dual-SIM picker

Every call asks which SIM when two are present, and the call log records which one was used.

Spam blocking

140-series telemarketing, private numbers and your own blacklist are rejected before the phone rings.

Caller ID popup

An incoming call shows the contact photo, name and number over any app, with answer and decline.

Fake call and flash

A scheduled fake call gets you out of a conversation; flash alert blinks the screen for a silent ring.

SMS built in

Threaded messages with Personal, OTP and Other categories, plus delivery reports and swipe actions.

OTP auto-delete

One-time passwords are recognised on the device and cleared after 24 hours, so they stop cluttering the inbox.

App lock

A PIN or pattern gate in front of the whole app, checked before any screen loads.

Appearance

System, Dark, Light or Black (AMOLED) themes with Green, Saffron or Indigo accents.

Install

Sideload the signed APK. It updates over older Nijatva Dialer builds signed with the same key.

1 — Download

Grab the latest APK from the releases page.

2 — Allow install

When Android asks, allow your browser or file manager to install unknown apps.

3 — Set as default

Open the app and choose it as your phone app so incoming calls reach it.

Prefer a cable? One command:

adb install -r Nijatva_Dialer_v1.5.apk

Privacy is a permission, not a promise

The manifest does not request android.permission.INTERNET. Nothing can be uploaded, because the operating system would refuse the connection.
